## 1. 快速开始

### 安装

通过 NuGet 安装：

```shell
dotnet add package DH.JPush
```

### 初始化客户端

```csharp
using Jiguang.JPush;

// appKey 和 masterSecret 从极光控制台获取
var client = new JPushClient("your_app_key", "your_master_secret");
```

> `JPushClient` 构造时会自动初始化 `Device`、`Schedule`、`Report` 子客户端。

## 2. 推送 API（JPushClient）

### 2.1 接口地址

| 常量 | 地址 | 说明 |
|------|------|------|
| `BASE_URL_PUSH_DEFAULT` | `https://api.jpush.cn/v3/push` | 默认地址 |
| `BASE_URL_PUSH_BEIJING` | `https://bjapi.push.jiguang.cn/v3/push` | 北京机房（低延迟） |

如应用分配在北京机房，可切换到北京地址以提升响应速度：

```csharp
client.SetBaseURL(JPushClient.BASE_URL_PUSH_BEIJING);
```

### 2.2 发送推送

```csharp
// 方式一：传入 PushPayload 对象（推荐）
HttpResponse response = await client.SendPushAsync(payload);

// 方式二：传入 JSON 字符串
HttpResponse response = await client.SendPushAsync("{...json...}");

// 同步版本
HttpResponse response = client.SendPush(payload);
```

### 2.3 校验推送（不实际发送）

```csharp
HttpResponse response = await client.IsPushValidAsync(payload);
HttpResponse response = client.IsPushValid(payload);
```

### 2.4 获取 CId 列表

CId（推送唯一标识符）可用于去重和追踪推送：

```csharp
// count: 数量，范围 [1, 1000]，默认 1
// type: "push"（默认）或 "schedule"
HttpResponse response = await client.GetCIdListAsync(count: 10, type: "push");
HttpResponse response = client.GetCIdList(10, "push");
```

### 2.5 批量单推（VIP 专属）

适用于每个用户推送内容不同的场景：

```csharp
var singleList = new List<SinglePayload> { ... };

// 按 RegistrationId 批量单推
HttpResponse response = await client.BatchPushByRegidAsync(singleList);

// 按 Alias 批量单推
HttpResponse response = await client.BatchPushByAliasAsync(singleList);
```

## 3. 推送载体对象（PushPayload）

`PushPayload` 是消息推送的核心载体，最终序列化为 JSON 发送给极光 API。

```csharp
var payload = new PushPayload
{
    // 推送唯一标识符（可选，用于去重）
    CId = "cid_xxx",

    // 推送平台："android" / "ios" / "all"（默认 "all"）
    Platform = "all",

    // 推送目标：字符串 "all" 或 Audience 对象（默认 "all"）
    Audience = "all",

    // 通知内容（与 Message 二选一或同时存在）
    Notification = new Notification { ... },

    // 自定义消息（与 Notification 二选一或同时存在）
    Message = new Message { ... },

    // 厂商通道三方通知
    Notification3rd = new Notification3rd { ... },

    // 短信补充
    SMSMessage = new SmsMessage { ... },

    // 推送选项（默认 iOS 开发环境）
    Options = new Options { IsApnsProduction = false },

    // 回调配置
    CallBack = new CallBack { Url = "https://your-server.com/callback" }
};

// 序列化为 JSON
string json = payload.ToString();
```

## 4. 推送目标（Audience）

`Audience` 用于指定消息推送的目标设备群体。当 `PushPayload.Audience` 为字符串 `"all"` 时广播全部设备；否则传入 `Audience` 对象。

```csharp
var audience = new Audience
{
    // 标签（OR 并集），每次最多 20 个
    Tag = new List<string> { "vip", "active" },

    // 标签（AND 交集），每次最多 20 个
    TagAnd = new List<string> { "beijing", "ios" },

    // 标签取补集（先 OR 再取反），每次最多 20 个
    TagNot = new List<string> { "blacklist" },

    // 别名（OR 并集），每次最多 1000 个
    Alias = new List<string> { "user_001", "user_002" },

    // Registration ID（OR 并集），每次最多 1000 个
    RegistrationId = new List<string> { "reg_id_1", "reg_id_2" },

    // 用户分群 ID（一次只能推 1 个）
    Segment = new List<string> { "segment_id" },

    // A/B 测试 ID（一次只能推 1 个）
    Abtest = new List<string> { "abtest_id" }
};

payload.Audience = audience;
```

## 5. 通知（Notification）

通知消息会显示在手机状态栏。

```csharp
var notification = new Notification
{
    // 全平台默认 alert 内容（各平台均适用）
    Alert = "您有一条新消息",

    // Android 平台独立通知配置
    Android = new Android { ... },

    // iOS 平台独立通知配置
    IOS = new IOS { ... },

    // 鸿蒙平台独立通知配置
    HMOS = new HMOS { ... }
};
```

### 5.1 Android 通知

```csharp
var android = new Android
{
    // 必填：通知内容
    Alert = "您有一条新消息",

    // 通知标题
    Title = "消息提醒",

    // 通知栏样式 ID（使用客户端 setPushNotificationBuilder 设置）
    BuilderId = 1,

    // 通知 Channel ID（Android 8.0+）
    ChannelId = "default_channel",

    // 通知优先级：-2 / -1 / 0（默认）/ 1 / 2
    Priority = 1,

    // 通知分类（Android 系统预定义类型）
    Category = "PROMO",

    // 通知样式：0（默认）/ 1（BigText）/ 2（Inbox）/ 3（BigPicture）
    Style = 0,

    // 通知提醒方式：-1（关闭）/ 0~7 按位组合（声音+震动+呼吸灯）
    AlertType = 7,

    // Style=1 时使用的长文本
    BigText = "这里是详细的长文本内容...",

    // Style=2 时使用的收件箱条目
    Inbox = new Dictionary<string, object>
    {
        ["line1"] = "第一行",
        ["line2"] = "第二行"
    },

    // Style=3 时使用的大图路径（URL 或本地路径）
    BigPicturePath = "https://example.com/image.jpg",

    // 通知右侧大图标（URL）
    LargeIcon = "https://example.com/icon.png",

    // 点击通知触发的 Intent（json 格式，key 为 "intent"）
    Indent = new Dictionary<string, object>
    {
        ["url"] = "intent:#Intent;component=com.example/.MainActivity;end"
    },

    // 附加自定义参数（客户端通过 Bundle 获取）
    Extras = new Dictionary<string, object>
    {
        ["order_id"] = "123456",
        ["type"] = "promotion"
    },

    // ===== VIP 专属字段 =====

    // 指定打开的 Activity 类名（android:name 属性值）
    URIActivity = "com.example.app.OrderDetailActivity",

    // 指定 Intent 的 access flags（十六进制字符串）
    URIFlag = "0x14000000",

    // 指定打开 Activity 的 Intent Action（见下方详细说明）
    URIAction = "com.example.app.OPEN_ORDER_DETAIL"
};
```

#### URIActivity / URIFlag / URIAction 详细说明

这三个字段均为 **VIP 专属**，用于控制点击通知后打开指定 Activity：

| 字段 | JSON Key | 值来源 | 示例 |
|------|----------|--------|------|
| `URIActivity` | `uri_activity` | `<activity android:name="...">` 属性值 | `"com.example.MainActivity"` |
| `URIFlag` | `uri_flag` | `Intent.java` 中 access flags 的取值 | `"0x14000000"` |
| `URIAction` | `uri_action` | `<intent-filter><action android:name="...">` 属性值 | `"com.example.OPEN_ORDER"` |

**URIAction 使用场景**：当客户端 AndroidManifest.xml 配置了 Intent Filter Action 时使用：

```xml
<!-- AndroidManifest.xml 客户端配置示例 -->
<activity android:name="com.example.app.OrderDetailActivity">
    <intent-filter>
        <action android:name="com.example.app.OPEN_ORDER_DETAIL" />
        <category android:name="android.intent.category.DEFAULT" />
        <data android:scheme="jpush" />
    </intent-filter>
</activity>
```

服务端推送时：

```csharp
new Android
{
    Alert = "您的订单已发货",
    URIAction = "com.example.app.OPEN_ORDER_DETAIL",
    Extras = new Dictionary<string, object> { ["order_id"] = "123456" }
}
```

```csharp
    // 自定义 Key-Value 对

    {
        ["action"] = "refresh",
        ["page"] = "home"
    }
```

## 7. 推送选项（Options）

```csharp
var options = new Options
{
    // API 调用标识（原样返回），不能为 0
    SendNo = 1001,

    // 离线消息保留时长（秒），默认 86400（1天），最长 10 天，0 表示不保留
    TimeToLive = 3600,

    // 要覆盖的消息 ID（有效期 1 天）
    OverrideMessageId = 12345678L,

    // iOS 是否推生产环境，默认 false（开发环境）
    IsApnsProduction = false,

    // APNs Collapse ID（折叠 ID，最长 64 字节）
    ApnsCollapseId = "order_collapse_001",

    // 定速推送时长（分钟），最大 1400，未设置则不启用
    BigPushDuration = 60
};

// 添加自定义扩展参数
options.Add("custom_key", "custom_value");
```

## 14. HTTP 响应（HttpResponse）

所有 API 均返回 `HttpResponse`：

```csharp
public class HttpResponse
{
    public HttpStatusCode StatusCode { get; set; }  // HTTP 状态码
    public HttpResponseHeaders Headers { get; set; } // 响应头
    public string Content { get; set; }             // 响应体（JSON 字符串）
}
```

**判断成功**：

```csharp
var resp = client.SendPush(payload);
if (resp.StatusCode == System.Net.HttpStatusCode.OK)
{
    // success，resp.Content 中包含 msg_id 等信息
    Console.WriteLine(resp.Content);
}
else
{
    // 失败，resp.Content 中包含错误码和描述
    Console.WriteLine($"推送失败：{resp.StatusCode} - {resp.Content}");
}
```

## 15. 完整示例

### 示例一：广播推送（全平台）

```csharp
var client = new JPushClient("your_app_key", "your_master_secret");

var payload = new PushPayload
{

    Audience = "all",
    Notification = new Notification
    {
        Alert = "欢迎使用我们的 App！",

        {
            Title = "新消息",
            Alert = "欢迎使用我们的 App！",

        },
        IOS = new IOS
        {
            Alert = "欢迎使用我们的 App！",
            Badge = "+1",
            Sound = "default"
        }
    },
    Options = new Options { IsApnsProduction = true }
};

var resp = await client.SendPushAsync(payload);
Console.WriteLine(resp.Content);
```

```csharp
    Notification = new Notification
    {
        Alert = "您的验证码为 123456，5分钟内有效"
    },
    SMSMessage = new SmsMessage
    {
        DelayTime = 60,       // App 推送失败后 60 秒再发短信
        TempId = 100001L,
        TempPara = new Dictionary<string, object> { ["code"] = "123456" }
    }
};

var resp = await client.SendPushAsync(payload);
```
